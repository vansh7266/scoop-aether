# Scoop bucket for Aether (Windows)

```powershell
scoop bucket add aether https://github.com/vansh7266/scoop-aether
scoop install aether
```

Then `aether setup`, `aether start`, and press Ctrl+Shift+Space.
Update with `scoop update aether`. Downloads come from
[aether-releases](https://github.com/vansh7266/aether-releases).
